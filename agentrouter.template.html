    What is AgentRouter?

    AgentRouter is an AI gateway and routing platform that provides compatible relay services and model routing.

    You point the coding tool you already use at one of two endpoints, drop in your key, and keep working.

    What are the benefits?

    • Relay Service Acts as an Anthropic-compatible proxy that lets coding agents and API clients connect seamlessly.
    • MCP Integration Uses Model Context Protocol (MCP) routing to discover and delegate tasks to specialized AI agents.
    • Zero-Friction Access Designed to allow quick integration with compatible apps without mandatory sign-ups or billing setup for basic use.
    • Works with what you already run Claude Code (CLI and VS Code), Codex, Cursor, Cline, Roo Code, Kilo Code, GitHub Copilot, opencode, Qwen Code, OpenClaw, Hermes, Pi / oh-my-pi, Trae and the Claude desktop app. No SDK to adopt — it is a base URL and a key.
    • Swap models without swapping tools One key reaches Claude Opus, GPT, GLM and DeepSeek models side by side. Changing model is an edit to one config line, so you can move a project to a cheaper or stronger model without re-authenticating or re-learning a client.
    • Quota that follows real work Quotas, model availability and rate limits are adjusted dynamically toward accounts with genuine, sustained usage — and idle accounts have unused resources reclaimed. If you actually code against it, that allocation works in your favour.

    Use it in oh-my-pi

    Add the following entry to your models.yaml and replace sk-xxx with your AgentRouter API key. New to it? See why omp. 

    providers:
  agentRouter:
      baseUrl: https://agentrouter.org/v1
      apiKey: sk-xxx
      api: openai-completions
      authHeader: true
      headers:
        User-Agent: opencode/1.0.0
      models:
        - id: claude-opus-4-8
          name: claude-opus-4-8
        - id: glm-5.3
          name: glm-5.3
        - id: deepseek-v4-flash
          name: deepseek-v4-flash
        - id: claude-opus-5
          name: claude-opus-5
        - id: gpt-5.6-sol
          name: gpt-5.6-sol
